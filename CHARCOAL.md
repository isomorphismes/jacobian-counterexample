# Charcoal interface

The existing Vite/TypeScript/Three.js site uses charcoal21 for the page, raised2F surfaces, interactive38 controls, border45, primaryF4 and secondaryB4 text, selection59 and focusB4. The default is explicit and does not follow the system color scheme. Layout, navigation, mathematical exposition, storage and rendering architecture remain unchanged.

The CSS changes only interface roles. The scientific SVG infographic, WebGL plot colors, hero artwork and video are preserved. No inversion or pixel filter is applied. The existing image overlay remains as artwork presentation; neutral controls surrounding the plots are themed separately. Downloaded papers and the generated knowledge book keep their own document presentation.

The maintained browser acceptance extends the existing JavaScript oracle. It executes phone, desktop and reduced-motion viewports under both system color schemes; checks actual computed charcoal surfaces and WCAG AA text outside the stated scientific/image exceptions; verifies keyboard focus and rejects a real white-root stylesheet mutation. Existing transcript, caption, preset, coordinate, vertex-count, WebGL, reduced-motion and fallback checks remain required. The fixture compares scientific source, main module, HTML and public media byte-for-byte with the preceding commit. The normal full publication verification remains enabled. New CI builds locally and never publishes Pages.

Current evidence is pending until hosted runs finish. This project has no Android APK. No deployment, release, or installed application is changed.
